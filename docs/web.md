# 网页实验管理

网页端可以独立管理实验，无需打开桌面导入窗口。所有操作使用同一个实验库的 `meta.json`、文件目录和 SQLite 索引。
页面静态资源随项目提供，不使用 CDN；完成首次依赖安装后，本机管理和局域网直传不需要外网，微信中转需要联网。

## 启动

**独立发布包**请双击 `启动实验管理.command`（Mac）或 `启动实验管理.cmd`（Windows）。
目标电脑自行安装依赖，首次启动自动创建程序旁的空 `实验库/`；具体要求见发布包 README。
源码构建与无数据发布流程见 [发布指南](release.md)。以下启动方式针对源码目录。

Mac 双击项目中的 `实验管理网页.command`，Windows 双击 `实验管理网页.cmd`。
首次启动会在项目内创建 `.venv-web` 并安装 `requirements.txt`，随后打开浏览器；不需要安装 Qt、Node 或前端构建工具。
需要 Python 3.10–3.13，Windows 上先安装 Python 并加入 PATH。直连同步的加密依赖随 `requirements.txt` 安装。
仓库还未初始化时，先运行 `python expvault.py init`。

已有 Python 环境可以直接使用：

```sh
python -m pip install -r requirements.txt
python expvault.py web
python expvault.py --root "/path/to/vault" web --port 8765
```

默认仅监听 `127.0.0.1:8765`。端口占用时可用 `--port 0` 自动分配。
终端会显示包含配对码的完整链接；`--no-open` 只显示链接，不自动打开浏览器。
按 Ctrl+C 停止服务，等待已接受的写操作完成；正在导入的任务会取消并保留已完成文件。

也可以点击桌面导入插件右上角的「网页管理」，直接进入当前实验。
这个入口仅供本机使用，网页服务随桌面窗口关闭；有网页后台任务时，桌面窗口会提示等待完成或取消导入。
工作区 `/web` 会启动独立的本机网页进程，停止方式为在启动终端中按 Ctrl+C。

## 项目工作空间

点击左侧当前工作空间名称，打开「项目工作空间」列表。列表显示名称、默认课题、操作人、
保存目录和当前空间；点击「进入工作空间」切换。手机上先展开导航栏，再点击工作空间名称。
点击「新建工作空间」，填写名称和可选的默认课题、操作人，然后「创建并进入」。
名称须为 1–80 字，不能与已有空间同名；默认课题留空时使用空间名称。

原实验库保留为默认空间，不移动已有实验。每个新空间都是空的独立实验库，使用自己的配置、
实验编号、数据目录、索引、文件标签、步骤、日志、上传暂存、备份和报告。
新空间使用默认配置，不复制旧空间的实验或备份目标；可在自己的 `config.json` 中调整。
实验编号可以重复，但文件和引用只在当前空间内查找，引用选择器不会跨工作空间引用资料。

切换会进入所选空间的独立网页会话，当前标签页的实验筛选和详情从新空间重新加载。
已开始的后台任务和手机扫码接收会话继续归属于原空间；切回原空间查看任务与暂存资料。
电脑导入窗口和手机接收页均显示工作空间与目标实验，确认后再发送文件。
正在向电脑发送文件时应先完成或停止发送；未保存表单仍会提醒。
颜色主题会随空间切换保留。其他已打开标签页保持各自的空间，不会被同时改为新空间。

独立网页入口 `python expvault.py web` 会恢复上次选择的空间；明确指定子空间的 `--root` 或桌面入口仍打开指定库。
关闭启动终端 / 按 Ctrl+C，或关闭持有网页服务的桌面窗口，会停止该进程打开的所有空间服务。

工作空间目录记录保存在原库的 `.expvault/workspaces.json`，新库位于原库的
`工作空间/ws-<编号>/`，显示名称不作为磁盘路径。移动到另一台电脑时，应连同隐藏的 `.expvault`
和整个 `工作空间/` 目录一起迁移。每个空间的常规实验备份只覆盖自己的实验，
不会自动备份其他空间或这个目录记录；迁移所有项目请复制完整原库目录。
CLI / GUI 也可用列表显示的绝对目录作为 `--root` 操作对应空间。
目录或配置缺失时，列表会提示不可用，不会静默重建空库覆盖原资料。

工作空间划分项目数据，不提供多人权限隔离。持有完整管理链接的可信使用者可以切换到已登记空间。
各空间在同一网卡的独立端口运行，仍遵循下述本机 / 可信局域网限制，不是公网服务器模式。

## 复制与批量模板

实验详情右上角「复用实验」可「复制实验」，或「按模板批量生成」。支持参数取值的全部组合与粘贴 Excel / CSV 每行条件，
先预览、再确认，每次最多 100 个。新记录独立编号，默认计划中；保留配置与可选仪器信息，不带已有测量值、结果、文件、步骤和日志。
操作步骤、标题变量、表格列名与复制范围见 [实验模板指南](templates.md)。

## 双向自动同步

左侧「自动同步」可配置坚果云等 HTTPS WebDAV、共享目录中转或 HTTPS 局域网直连，定期双向合并所有工作空间的实验资料。
页面显示当前主机名 / 地址、最近通信、按阶段更新的同步进度，以及可下载的本机同步日志（保留最近 1000 条）。
可分别选择是否同步照片、视频，并限制照片大小；筛选不删除已有文件。不同字段自动合并，同处修改可在网页比较并处理，文件冲突保留副本。
历史备份和导出报告仍由各电脑独立保存。配置只允许在本机浏览器操作。
WebDAV 预填坚果云服务地址，使用第三方应用密码；应用密码仅保存本机，不返回状态或写入同步日志。
两台电脑的接入步骤、校园网方案、筛选与恢复说明见 [自动同步指南](sync.md)。

## 校园网与手机访问

**电脑连校园网不影响本机浏览器使用。** 本机管理无需手机和电脑处于同一个网络。
校园网、访客 Wi-Fi 常有终端隔离，不能假定同一 SSID 或同一校园网就能互传。

要从手机使用完整管理界面，先建立可直接互通的连接，例如电脑 / 手机独立热点，或设备支持的 USB 共享网络。
然后明确绑定电脑上对应网卡的 IPv4 地址：

```sh
python expvault.py web --host 192.168.137.1 --port 8765
```

将示例地址替换为电脑的实际热点 / USB 共享网卡地址，在手机浏览器打开终端显示的完整链接。
根据系统提示允许 Python 访问本地 / 专用网络。插件不会自动修改防火墙或校园网设置。
无法建立直连时，通过系统工具先把手机资料导出到本机，再使用网页选择文件或文件夹；U 盘导入不需要网络互通。

网页管理链接允许查看、编辑并切换已登记的工作空间，区别于「手机扫码传入」仅接收指定实验资料的链接。
配对码每次启动随机生成，12 小时有效；会话保存在浏览器当前会话中，刷新可继续使用。
关闭服务后链接失效。服务使用 HTTP，仅用于本机或可信局域网，不用于公网，不配置路由器端口映射。
这是单个可信使用者的实验工作台，没有多用户账号、角色隔离或公网托管功能。

## 扫码传入与 Windows 热点

只传资料时，无需向手机提供整个实验库的访问链接。在实验详情点击「扫码传入」，
或在「导入资料」窗口展开「手机扫码传入」，选择电脑接收网卡并生成资料二维码。
手机扫描后选择原始图片、视频或数据文件，可填写批量 / 逐文件标签。默认发送到电脑暂存，在电脑端核对清单后点击「发送并导入」。
从 NAS 编辑主机生成二维码时，手机可在「上传位置」选择「直接导入 NAS 的当前实验」。导入失败时，已完整接收的文件会留在电脑暂存区。

Windows 10 / 11 的本机浏览器提供「一键开启 Windows 热点并生成二维码」：

1. 电脑先连好可共享的校园网、有线网络或 Wi-Fi，再点击开启按钮。
2. 系统确认热点已开启后，页面显示真实热点名称、密码和 WLAN 连接二维码。手机使用系统相机或 WLAN 扫码连接。
3. 页面识别热点网卡后会同时生成当前实验的资料二维码；连好热点，再扫描第二个二维码上传。
4. 若网卡未及时出现，刷新热点状态，选择实际热点地址后生成资料二维码。不识别 WLAN 二维码的手机可手动输入名称和密码。

热点控制使用 Windows 系统接口，沿用当前热点配置，不预设 IP 或重置密码；
网卡、驱动、系统版本或组织 / 校园网策略可能阻止开启，页面会显示失败原因，并提供「打开系统热点设置」。
不绕过系统策略。只有从 `127.0.0.1` / `localhost` 打开的本机管理会话可以控制热点、读取密码，局域网客户端不能执行这些操作。
本次服务开启的热点可以在页面关闭；退出服务时也会尝试关闭。原本已开启的热点不会自动关闭。
Mac 可选择已有热点、USB 共享网络或可互通的局域网，不提供 Windows 热点开关。

资料二维码随机配对，只能向对应实验传入文件。每个接收会话有效 2 小时，可单独关闭；
关闭导入窗口后仍可接收，再打开窗口会恢复暂存文件。关闭网页服务会停止所有接收会话，完整暂存仍会保留。
所有二维码在本机生成，不使用外部二维码服务。只在可信网络使用接收链接。

## 微信网页文件传输助手

导入窗口中可一键打开[微信官方网页文件传输助手](https://filehelper.weixin.qq.com/)。
手机按官方页面扫码连接后发送资料，在官方网页下载文件，再回到实验工作台选择下载的文件、添加标签并确认导入。
此方式通过微信中转，适合校园网阻止手机与电脑直接互通、但双方都可访问微信的场景。

**发送照片请勾选「原图」；视频优先按「文件」发送原始视频，避免压缩。**
下载后核对格式、大小与内容；只在手机本地完整下载原片后发送，避免截图、缩略图或二次压缩副本。
微信登录和文件收发在官方页面完成；实验工作台不会读取微信账号或自动拉取网页中的文件。

## 页面与日常工作流

| 页面 | 可用操作 |
| --- | --- |
| 工作概览 | 实验统计、进行中实验的紧凑卡片（每页 12 个，可翻页）、最近实验和操作记录 |
| 实验项目 | 搜索、状态筛选、包含归档、分页、新建实验，列表直接展示样品与关键参数 |
| 实验概览 | 直接修改状态；编辑标题、日期、课题、器件、批次、类别、操作人、实验标签、目的、条件、结果、结论、备注与参数 |
| 步骤与日志 | 新增和修改步骤、上传过程图片、引用已导入图片、追加带时间戳日志 |
| 文件资料 | 文件 / 文件夹上传、暂存恢复、导入确认、标签检索、标签修改、预览、下载、删除及目录扫描 |
| 变更记录 | 查看最近 100 条实验变更 |
| 备份与校验 | 选择实验校验 SHA256、创建已配置目标的备份、查看备份历史、导出 HTML 看板和 Excel / CSV 台账 |
| 自动同步 | 配置共享目录 / 加密直连、视频与照片筛选、查看状态、暂停 / 恢复、比较处理冲突 |

新建或编辑实验时，参数按「名称 / 值」逐行填写，无需编写 JSON。
实验编号、目录与创建时间不在表单中修改；调整实验日期不会重命名目录或改变编号。
归档保留数据，恢复时进入「已完成」状态；需要继续实验时可点击「修改状态」改为「进行中」。

实验详情标题旁、实验列表的状态列和首页进行中卡片都有「修改状态」入口。
选择「进行中 / 已完成 / 计划中 / 已中止」后点击「保存状态」，立即刷新列表和首页统计，资料与记录保留。
「编辑实验」表单也可修改状态；已归档的实验须先恢复，再调整状态。并发修改会提示刷新核对，不覆盖其他窗口的新记录。
首页进行中实验每页展示 12 个，使用上一页 / 下一页浏览全部，或点击「查看全部」进入筛选列表；
卡片保留样品、前 2 项关键参数、操作人与日期，置顶参数优先，不再只展示 3 个实验。

实验编辑和步骤修改携带元数据版本，另一个窗口已经更新时会拒绝覆盖，请刷新核对后再保存。
页面关闭前会提醒尚未保存的表单；日志采用追加方式，不覆盖此前内容。
归档操作和恢复操作也写入实验变更记录。

## 参数速览与颜色主题

### 工作台布局与键盘操作

工作概览顶部显示当前工作空间，统计卡片可点击：实验总数进入包含归档的完整列表，
进行中 / 已完成进入对应状态列表，实验资料进入文件页面。快捷入口会清空旧搜索和分组筛选。
进行中的实验仍每页展示 12 个；卡片与统计区域按可用空间调整列数。

使用键盘时，首次按 Tab 可选择「跳到主要内容」；切换页面后，焦点移到新页面标题，浏览器标签页标题也随之更新。
实验详情的页签使用左右方向键、Home / End 移动焦点，再按 Enter 或空格切换内容。
手机导航提供关闭按钮，支持 Escape 和点击遮罩关闭；打开期间，背景控件不可操作，关闭后焦点返回菜单按钮。
从手机尺寸放大为桌面尺寸时，导航会恢复为固定侧栏。

浅色主题采用明亮侧栏和更清晰的卡片层级，其他配色继续覆盖全部界面。
触屏上的主要按钮、图标按钮与页签有更大的点击区域；系统开启「减少动态效果」时关闭界面过渡。

### 参数与配色

实验详情顶部集中展示样品编号、工艺批次、操作人和实验日期。关键参数独立展示名称与完整数值，
默认显示前 6 项；点击「查看全部」可展开其余参数。「编辑参数」会直接定位到编辑窗口中的参数区域。
结果与观察、结论与下一步置于概览前部，右侧可直接记录步骤或追加日志。

点击参数卡片的图钉可置顶最多 6 项常看参数，取消置顶可恢复原顺序。
首页进行中卡片、实验列表和详情页都会优先显示置顶参数；切换到步骤或文件页签时仍保留参数区。
显示顺序仅作为当前浏览器的偏好保存，按实验库和实验编号区分，不改写实验元数据或参数值，也不随备份同步。
手机页面保留样品与参数信息，参数值较长时自动换行。

页面右上角「颜色主题」可选浅色、深色、青竹、暖砂、雾紫、深海或跟随系统，弹出编辑窗口中也有同样的切换入口。
青竹采用绿色、暖砂采用米色与棕色、雾紫采用浅紫色、深海采用深色底与青色；配色覆盖侧栏、背景、按钮和参数卡片。
选择会保存在当前浏览器，刷新和重新打开页面后保留；跟随系统模式会响应系统外观的变化。
主题切换不会重载页面或清空未保存的表单。浏览器禁止本地存储时，仍可切换，偏好只在本次页面中有效。

## 折叠参数与测量区域

实验详情的「关键实验参数」和「仪器与对照测量」右侧均有「折叠 / 展开」。
两块区域可分别将整个矩形卡片（包括标题栏、内容和编辑按钮）隐藏，方便直接查看步骤与日志。
隐藏后只保留卡片外的紧凑「展开…」入口和数量，点击即可恢复整块卡片。
默认展开；浏览器会按工作空间和实验记住各自状态，刷新或切换页签后保留，其他实验的状态独立。
这只是本机浏览器的显示偏好，不修改实验记录，也不随备份或双向同步传到其他电脑。
浏览器禁止存储时，本次页面内仍可切换，刷新后恢复默认展开。

## 仪器型号与多次对照测量

实验详情的关键参数下方新增「仪器与对照测量」：

1. 点击「添加仪器」，填写仪器名称 / 编号和型号，例如「源表 01 / Keithley 2400」。同型号的不同仪器可用名称或编号区分。
2. 在该仪器下点击「记录测量」，填写测量组名称、时间、操作人和参数。例如「退火前」「退火后」都可以记录「电流」「栅极电压」。
3. 点击某次测量的「复制为新测量」，沿用参数名称和值，再修改本次结果；新记录有独立编号，不覆盖原测量。
4. 点击「编辑」修正单次测量，或「编辑仪器」修正名称和型号。不同测量的同名参数并排列出；缺少的参数显示为 `—`，手机可在表格内横向滚动。

原有样品 / 工艺参数保留，可继续置顶。单次测量内的参数名称须唯一；重复测量应分别建组，
不必把参数名改成「电流1」「电流2」。每次测量独立保存时间与操作人，时间按当前设备当地时间显示。
每个实验最多 20 台仪器，每台最多 50 组测量，每组最多 100 项参数。

记录保存在实验 `meta.json.measurement_groups`，旧实验无须手动迁移，SQLite 索引自动补列，重建后仍可恢复。
仪器型号、测量名称和参数可通过实验搜索检索；修改其他实验字段不会清空仪器记录。
备份与恢复包含全部仪器和测量；实验 README 和 HTML 看板显示对照表，Excel 台账新增「仪器对照测量」工作表，
CSV 降级导出使用独立 JSON 列保存完整结构。编辑仍使用版本检查，避免旧窗口覆盖较新记录。

## 文件、上传和标签

在实验详情「文件资料」中导入，或从左侧文件资料选择目标实验。可以多选文件、选择整个文件夹，也能拖入文件。
文件夹选择会保留内部层级；浏览器对文件夹选择的支持因设备而异，手机通常使用系统文件选择器选择照片、视频或文件。

每个文件有独立的标签输入框，也能将标签批量追加到勾选项。
标签支持中文和空格，以中文 / 英文逗号、分号或换行分隔；最多 50 个，单个最多 80 个字符。
导入后的标签可选择追加、整体替换或清空，并支持按文件名 / 标签筛选。
实验项目搜索也会匹配文件标签。标签存于 `meta.json.file_tags`，扫描或重建索引后仍可恢复。

上传先流式写入 `.expvault/web/inbox/`，每文件默认上限 20 GB；点击「发送并导入」才写入实验目录。
页面刷新、断网或服务重启后，已完整传到电脑的暂存文件仍可恢复。未传完的文件不入清单，并清理临时副本。
成功导入 / 按内容去重后清理对应暂存；取消任务保留已完成实验文件，失败项可以核对后重试。
修改暂存文件的标签会以确认导入时的值保存，重复内容导入会合并到已有文件标签。
「移除勾选的暂存文件」仅删除网页暂存，不删除已归入实验的文件或本机原始文件。

默认图片 / 视频分别进入 `04_notes/photos/`、`04_notes/videos/`，数据进入 `01_raw/`，也可选择已配置的文件角色。
复制保留原格式，先计算摘要并重读副本校验，再提交目标文件；同名自动加后缀，相同内容可去重。
网页和桌面端共用导入器。若源是手机或 U 盘，原片仍保留在源设备。

图片、视频能否直接显示由浏览器格式支持决定；视频支持 HTTP Range，播放无需先加载整个视频。
UTF-8 文本预览最多 200 KB，其他格式可下载原文件。HTML / SVG 等主动内容以附件下载，不作为管理页面执行。
文件删除必须先预览清单并输入 `DELETE`；元数据、日志和仍被步骤引用的图片受到保护。

## 步骤图片

步骤可同时包含正文、多张新上传的图片及从本实验资料库选择的图片。
新增图片会复制为步骤自己的副本，已导入图片的标签也会保留在新副本上。
支持 PNG / JPEG / GIF / WebP / BMP / TIFF，并检查文件头。
HEIC 可保留原片导入文件资料；用于浏览器内的步骤展示时，建议先另存 JPEG / PNG。
「解除已有图片关联」保留磁盘文件；如果确定不再需要，可在文件资料中单独删除。

## 现场记录、步骤与日志引用文件

「记录步骤」「追加日志」和「修改日志引用」都有文件库选择器，默认显示当前实验资料，
也可搜索并切换到其他实验。按文件名或文件标签筛选、翻页、勾选，可引用图片、视频和任意已登记的数据文件，
每条记录最多 100 个；多次切换来源实验和筛选条件会保留已选项。
步骤可以只引用文件，不必再次上传或填写重复说明。

引用直接关联来源实验编号与文件相对路径，**不会复制、移动或修改原文件**；本次新上传的步骤图片仍按原流程保存独立副本。
记录中的引用卡片显示文件名、来源实验、原路径和标签，可以预览或下载原文件。
现场记录面板也会展示最近步骤和日志的引用。引用时同时保存大小、SHA256 和标签快照，用于追溯；
读取时结合当前索引和磁盘状态提示文件缺失 / 已变化，确认内容是否相同仍应执行来源实验的完整性校验。

编辑步骤可添加、移除引用；新日志保存后可通过「修改引用」调整附件关联，原日志正文和时间保持不变。
被任意实验的步骤或日志引用的文件受到删除保护，应先在相关记录中解除引用，再删除原文件。
重建索引不会丢失引用关系。跨实验引用需要保留来源实验，备份整个实验库时会一并保存；单独拷贝某个实验目录不会自动携带其他实验的原文件。

以前的日志文件保持原样，新日志采用可识别的 Markdown 区块，并在 `meta.json.journal_entries` 中保存结构化信息。
浏览器会同时显示旧日志和新条目；若有人手动改过新条目的 Markdown 区块，修改引用会拒绝覆盖，并保留外部修改供核对。
日志文本过长时仍只展示前 256 KB，完整内容可下载 `04_notes/日志.md`。

## 科研文字的上标与下标

实验标题、样品、目的、条件、结果、备注、步骤、日志和参数输入框提供「下标」「上标」按钮。
选中文字后点击按钮，或直接输入花括号语法，输入框下方会即时预览；保存后详情、列表、现场记录和参数卡片按格式显示。

| 输入 | 显示效果 |
| --- | --- |
| `MoS_{2}` | MoS₂ |
| `V^{2}` | V² |
| `cm^{-2}` | cm⁻² |
| `x_{i}^{2}` | xᵢ² |

支持中文和多字符上下标，已有 Unicode 字符（如 MoS₂）也可继续使用。
这是文字上下标，不是完整 LaTeX / 公式编辑器；输入原样保存在元数据中，页面只渲染受限的上下标语法，不执行用户 HTML。
不完整的花括号保留为普通文字。搜索 `MoS2`、`MoS₂` 或 `MoS_{2}` 可找到同一科学名称。
生成的实验 README、步骤离线页面和新日志 Markdown 也会保留上下标显示及资料引用链接，不依赖外部排版服务。

实验备注还支持加粗：选中文字点击「加粗」，或直接输入 `**必须复核**`。
输入时即时预览，保存后在实验概览、实验 README 和 HTML 看板中以粗体显示，
也可组合使用 `**MoS_{2}**`。只识别受限的加粗与上下标语法，用户输入的 HTML 保持为文字；未闭合的 `**` 按原文显示。

## 后台任务和数据一致性

右上角的任务按钮可查看进度、结果和错误，导入任务支持取消；校验和备份开始后需等待完成。
成功校验会列出检查文件数、通过数量与数据量；发现异常会列出内容变化、丢失和未登记的路径。
导出不依赖 Excel：安装了 openpyxl 则生成 XLSX，未安装时自动降级为 CSV。
备份只使用 `config.json` 中已启用的目标，不自动裁剪旧快照，也不改变备份配置。

每次写操作使用稳定的请求编号，任务结果保存在 `.expvault/web/jobs/`。
同一编号和内容重试返回原结果，不重复创建实验、追加日志或导入。
服务中断时，未确认完成的任务会标记「需要核对」，不会自动重放；请先检查实际数据。
任务记录属于网页运行状态，不是实验权威数据，不替代实验元数据和备份。

同一实验库同时只启动一个完整网页服务。网页 / GUI / Harness 共用 `harness.lock` 串行写入，
旧 CLI 的部分写命令仍未使用这把锁，应避免与网页同时修改同一实验。
在多个浏览器窗口中编辑也会检查版本，避免旧表单覆盖较新记录。

## 开发验收

```sh
python -m unittest discover -s tests -v
```

`tests/test_web.py` 使用临时实验库与真实 HTTP，覆盖会话、请求边界、CRUD、版本冲突、任务重试、上传、标签、扫码接收、
步骤图片、日志、Range 下载、删除保护、归档、扫描、备份与导出。不会操作用户真实实验。

浏览器验收是可选的开发依赖，需要 Node 20+，运行服务本身无需 Node：

```sh
npm ci --prefix tests/browser
npx --prefix tests/browser playwright install chromium
npm test --prefix tests/browser
```

需要指定 Python 环境时，将 `EXPVAULT_TEST_PYTHON` 设为该环境的 Python 路径。
可通过 `EXPVAULT_WEB_ARTIFACTS` 指定截图目录，默认位于系统临时目录。
仅验收本次界面改进时可运行 `EXPVAULT_MODERN_ONLY=1 npm test --prefix tests/browser`（Windows 请先设置同名环境变量）。
该组检查包含统计快捷筛选、加载状态、跳转焦点、手机原生导航、320–1440 像素布局、键盘页签、深色主题与减少动态效果。
浏览器脚本自行创建与清理独立测试库，验证桌面和手机尺寸下的新建 / 编辑、步骤与图片、日志、上传 / 标签、
预览 / 下载、校验、归档、备份 / 导出、删除、扫码上传及标签、微信入口与刷新认证。
Windows 热点按钮的浏览器验收使用模拟响应，操作结果与所有权由单元测试验证；不会切换测试机的真实网络。
CI 同时运行 macOS / Windows HTTP 检查、Windows PowerShell 语法 / 只读网卡枚举和 Chromium 浏览器验收。
真实 Windows 热点开启及手机 WLAN 扫码连接仍需在目标网卡和校园网环境中验收。
浏览器验收还检查参数首屏位置、置顶与刷新恢复、元数据未被显示偏好修改、手机参数布局，
以及所有配色的参数文字对比度、系统主题跟随、主题持久化和切换时保留表单内容。
`tests/test_references.py` 和 HTTP / 浏览器用例进一步覆盖跨实验引用、删除保护、旧日志保留、引用修改、
缺失 / 变化提示、备份恢复、上下标输入显示、HTML 转义和科学名称搜索。
`tests/test_workspaces.py` 覆盖新建 / 列出 / 选择、重名与目录边界、目录记录持久化、整库迁移、
相同实验编号的数据隔离、切换时后台任务与手机接收归属、启动恢复和全部服务关闭。
桌面与手机浏览器验收还实际创建、切换两个空间，并检查文件隔离和主题保留。
状态回归覆盖状态往返切换、刷新与重启保存、统计与筛选同步、归档和并发保护；首页使用 14 个进行中实验验收紧凑布局与翻页。
空工作空间在提供网页服务前初始化索引，回归覆盖首页首次并发读取，避免初始化竞争导致读取失败。
`tests/test_measurements.py` 进一步覆盖同仪器重复参数、编号与时间校验、旧索引升级、备份恢复、导出及备注加粗安全渲染。
HTTP 和桌面 / 手机浏览器验收包含新增仪器、记录 / 复制 / 编辑测量、刷新保留、横向对照及备注加粗预览。

## 实验编组

「实验项目」支持多选后加入或移出分组、按组或未分组筛选；「管理分组」可重命名、合并或解散。
一个实验可有多个组，最多 20 个。新建、编辑、复制和批量生成窗口都可设置分组，分组随实验同步、备份和导出。
操作仅影响当前工作空间，解散分组保留实验与文件。详见 [实验编组指南](groups.md)。

## 直接使用 NAS 实验库

左侧「NAS 实验库」可以连接系统已挂载的共享目录，并保存当前电脑的连接路径。
编辑主机可读写，其他电脑以只读方式打开；只读模式同时在页面和后台拒绝修改与上传。
实验资料留在 NAS，SQLite 索引、任务状态、导出报告和终端状态保存在本机。
共享库不启用双向同步，目录断开时不会初始化本地替代库。详细步骤见 [NAS 使用指南](nas.md)。
