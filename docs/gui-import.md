# 桌面导入插件：手机、U 盘、文件与标签

## 启动

在项目根目录双击：

| 平台 | 入口 |
| --- | --- |
| macOS | `导入实验资料.command` |
| Windows | `导入实验资料.cmd` |

首次启动会在项目内创建独立的 `.venv-gui` 环境，并联网安装 `requirements-gui.txt`；之后直接打开窗口。
需要先安装 Python **3.10–3.13**；Windows 安装时勾选 Add Python to PATH。
GUI 使用 Qt / PySide6 Essentials，最低 Qt 6.8.3，对应 macOS 12+（Intel / Apple Silicon）以及 Windows 10（1809+）/11（64 位）。
pip 会按当前 Python 和系统版本选择兼容的 Qt 安装包；较新 Qt 版本可能要求较新 macOS。
最低平台范围参考 [Qt 6.8 支持列表](https://doc.qt.io/qt-6.8/supported-platforms.html)，具体 Python 限制见 [PySide6 Essentials](https://pypi.org/project/PySide6-Essentials/)。
CLI 的依赖与启动方式不受影响；此插件没有要求安装 WebEngine，也不需要管理员权限。

也可以用自己的 Python 环境：

```sh
python -m pip install -r requirements-gui.txt
python expvault.py gui
python expvault.py --root "/path/to/vault" gui E20261109-001
```

已有工作区里输入 `/gui`，会在独立进程打开当前实验的导入窗口，可以继续使用终端。
需要完整实验管理时，点击桌面窗口右上角的「网页管理」，可在浏览器中管理实验、步骤、日志、文件、校验与备份。
保持桌面窗口开启即可持续使用；独立网页服务、校园网连接方式和手机访问见 [网页管理指南](web.md)。
仓库尚未初始化时先运行 `python expvault.py init`。窗口中可以新建实验，也可以切换其他已初始化的实验库。
若 macOS 提示脚本没有执行权限，在项目目录运行 `chmod +x 导入实验资料.command`。

## 从 U 盘或本机导入

1. 选择目标实验，或点击「新建实验」。
2. 点击「选择文件」「选择文件夹 / U 盘」，也可直接从 Finder / 资源管理器拖入文件或文件夹。
3. 核对清单、勾选文件、填写文件标签，然后点击「开始导入」。
4. 成功后在「已导入资料 / 标签检索」查看；双击文件名通过系统默认应用预览。

支持任意数据文件，不限制 CSV、Excel、仪器原始格式。图片包含 HEIC/HEIF、JPEG、PNG、TIFF、DNG 等，
视频包含 MOV、MP4、AVI、MKV 等；插件复制原文件，不转码、不压缩。预览能力取决于系统安装的应用/编解码器。
导入文件夹会递归保留所选文件夹的名称及内部层级；系统隐藏文件、符号链接和仓库排除规则中的临时文件会跳过。
Android MTP 和 iPhone 照片库若没有普通文件系统路径，请使用下面的手机扫码，或先用系统工具导出到本机再选择。

默认分类：

| 类型 | 默认目标 |
| --- | --- |
| 图片 | `04_notes/photos/` |
| 视频 | `04_notes/videos/` |
| 数据及其他文件 | `01_raw/` |

以上使用仓库的 `structure` 中 `note` / `raw` 对应目录，也可以在窗口底部改选文件角色。
图片导入不会自动创建实验步骤；需要把图片关联到步骤时继续用 `/step -i`。

## 校园网环境（默认场景）

校园网通常存在终端隔离：同一 SSID、同一校园网或电脑接有线校园网，并不表示手机能直接访问电脑。
本插件的扫码接收是本地直传，不会通过学校认证服务器、外网中继或云盘绕行。

**无需改变校园网连接时**，使用主窗口的「USB 手机 / 相机」。助手可以打开 Mac「图像捕捉」
或 Windows「此电脑」，通过系统工具将资料导出到本机，然后在同一个助手里选择导出文件夹、打标签并导入。
Windows 也可以使用「照片」应用的导入功能；iPhone 根据系统配置可能需要 Apple Devices，Android 需要允许文件传输。
Mac 的 Android 设备可尝试照片传输（PTP）模式，若系统不识别，改用下面的热点方式。
系统 USB 导出参考 [Apple 指南](https://support.apple.com/en-ie/120267) 和 [Microsoft 指南](https://support.microsoft.com/en-gb/windows/apps/photos/import-photos-and-videos-from-phone-to-pc)。

**希望直接手机扫码时**，先建立独立连接，再开启接收：

- 手机连接电脑开启的热点，或电脑临时连接手机热点。
- 也可在手机/系统支持的情况下使用 USB 共享网络；接收器选择对应共享网卡的地址。
- 电脑能共享有线校园网时，可以保留有线连接并开启 Wi-Fi 热点；具体由操作系统和学校策略决定。

热点不要求外网中继或云服务，但是否能开启、是否允许手机与电脑互访由设备与网络设置决定；无法互通就使用 USB 导出。
桌面扫码窗口默认展示校园网说明，提供独立热点 / 普通局域网模式，用户自行开启热点与切换网络，此窗口不会修改系统网络设置。
需要 Windows 一键开启热点和 WLAN 连接二维码时，可进入「网页管理」后使用「扫码传入」；
网页导入窗口也提供微信网页文件传输助手入口及原图 / 原视频提醒，见 [网页管理指南](web.md)。

## 从手机直接传入（独立热点或可互通局域网）

1. 按上节建立可互通的热点或局域网连接。在桌面端选好目标实验，点击「手机扫码传入」。
2. 选择与手机同网段的网卡地址，点击「开启手机传入」。
3. 手机相机扫码，用浏览器选择照片、视频或数据；可设置批量标签，也能逐文件修改标签。
4. 点击手机页面的「发送到电脑」，保持浏览器前台、屏幕点亮。
5. 关闭电脑的扫码窗口，回到主窗口检查清单与标签，点击「开始导入」。

手机无需安装应用。手机上传只进入 `.expvault/inbox/`，桌面端确认后才复制到实验。
传输中断的文件不会加入清单；手机页面的发送按钮可以重试失败项，已经成功项不会再次发送。
网络断开恰好发生在响应阶段时，重试可能产生多份暂存副本，最终导入会按内容去重。
暂存文件和手机端标签在窗口重启后可恢复；仅在成功导入/去重后清理对应暂存副本。
从清单移除或清空清单**不删除**未导入的手机暂存，下一次启动仍会恢复。

接收端只在开启时监听所选局域网 IPv4 地址，配对令牌每次随机生成，链接 2 小时有效，关窗立即停止接收。
传输使用 **HTTP，请在可信局域网使用**。它是临时接收器，不是公网服务，不能配置路由器端口映射。
默认单文件上限 20 GB，大文件按块落盘；超出上限可从 U 盘/文件夹导入。

连不上时，检查 Windows 防火墙是否允许 Python 的「专用网络」、macOS 是否允许本地网络访问；
关闭 VPN 或选择正确网卡；校园/访客 Wi-Fi 的设备隔离可能阻止互联，可改用手机热点。
暂停照片云同步会影响尚未下载的原片，先在手机上下载原文件，再选择发送。

## 文件标签

- 在清单的「文件标签」列双击，编辑单个文件的标签。
- 在「批量标签」输入逗号分隔的内容，点击追加；有选中行时仅应用到所选，否则应用到全部待导入文件。
- 支持中文/英文逗号、分号、换行分隔；空格属于标签内容，例如 `样品 A` 是一个标签。
- 每个文件最多 50 个标签，单个标签最多 80 个字符，重复标签自动合并；标签可以留空。
- 在「已导入资料」按文件名或标签筛选，也可选中文件后「修改所选文件标签」。批量修改为整体替换，留空清除。
- 相同内容被去重时，本次标签会合并到已经存在的文件，已有标签保留。

文件标签与实验整体的 `tags` 相互独立，权威数据在实验的 `meta.json` 中：

```json
{
  "file_tags": {
    "04_notes/photos/IMG_0001.HEIC": ["样品 A", "退火前"],
    "01_raw/IV/run1.csv": ["样品 A", "电学"]
  }
}
```

SQLite 的 `files.tags` 是 JSON 缓存，旧数据库首次打开会自动补列。
`scan`、`sync`、`rebuild` 会从 `meta.json` 恢复文件标签。README 文件清单及 Excel 文件清单也包含标签。
普通 CLI 的 `search "退火前"` 可检索文件标签；`files.list` / MCP 文件列表会返回 `tags` 数组。

## 复制、校验与取消

始终复制，保留 U 盘/手机/本机原文件。每个文件先写临时副本，流式计算 SHA256，重读目标副本校验后再提交；
同名不同内容自动加数字后缀，大小写也视为重名，以便跨平台搬迁。
默认按当前实验已登记的实际文件内容去重；可取消勾选「跳过相同内容」以保留相同内容的不同副本。
取消时保留已完成文件和标签，清理未完成副本，失败文件继续留在清单，可再次导入。
若源文件在扫描后变化、复制中被修改、设备拔出、磁盘不足或校验失败，会显示逐文件错误。

GUI 与 Harness/MCP 使用相同的 `harness.lock` 串行写入。
旧 CLI 的部分写操作不持有这把锁，请等 GUI 导入完成后再对同一实验执行修改、删除或备份。
复制已完成但后续元数据/磁盘写入失败时，会保留已校验的实验副本和原始文件；修复磁盘问题后先 `scan` / `verify` 检查再重试。

## 开发验证

```sh
python -m pip install -r requirements-gui.txt
python -m unittest discover -s tests -v
```

GUI 测试在临时实验库中离屏运行，验证批量/单个文件标签、后台导入、勾选、检索、CLI 与工作区入口。
HTTP 集成测试覆盖上传、令牌、过期、路径、大小限制、中断与暂存恢复；导入器测试覆盖复制校验、重名、去重、取消、
标签重建和旧数据库迁移。`.github/workflows/gui.yml` 提供 macOS / Windows、Python 3.10 / 3.13 的兼容矩阵。
